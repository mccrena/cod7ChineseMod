# v1.0-beta 测试步骤

先确认安装器显示成功，安装回执位于游戏目录 zh-dub-mod-state/v1.0-beta.json。

1. 运行游戏根目录 BlackOps.exe，从“关卡选择”重新开始古巴。先听开场审讯对白：记录哪些中文、哪些英文。梅森 7 段常驻对白仍英文是已知问题。
2. 跳过过场，确认能进入酒吧并正常走动，随后走到第一条街道。若仍有着色器报错，保存完整截图并报告安装回执；不要只写“闪退”。
3. 听卡洛斯、伍兹、鲍曼与梅森的介绍对白，检查角色是否对应、句子是否完整。部分字幕仍缺失是已知问题，不能据此判定该句没有语音。
4. 连续玩过一段战斗，记录语速过快、句尾缺字、声音突变、杂音、接话重叠和翻译不符合场景的位置。
5. 选另一关，例如沃尔库塔或拜科努尔，检查切关和存档读取是否正常。不同关卡分别记录，不用一关的结果代表全战役。
6. 关闭游戏，运行卸载，确认覆盖包恢复到安装前内容，再按需要重新安装。

问题反馈至少包括：关卡及检查点、说话角色、台词或字幕、预期表现、实际表现、能否重复出现。截图或短录音可辅助定位。

发布包只做过离线资源与安装流程检查，没有代替上述游戏运行测试。
