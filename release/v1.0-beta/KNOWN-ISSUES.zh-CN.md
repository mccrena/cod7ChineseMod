# v1.0-beta 已知问题

1. **开场中英混播。** 开场梅森的 7 段对白从 frontend Fastfile 内的常驻音频加载，之前的 IWD 替换没有覆盖这条路径。“醒醒”变成中文不代表后续全部中文。此缺口尚未修复。
2. **部分语句过快，可能截尾。** 上轮试听清单有 395 条记录的变速超过 1.10 倍；旧编码代码还允许裁掉超长尾部。本版保留这些试制结果作为测试对象，尚未逐条完成返工，不能宣称全句完整或表演合格。19 条已有古巴语气修订优先使用原修订音频。
3. **古巴字幕修复暂不随默认包安装。** 原字幕地图重建将 66 处顶点格式错误重置，导致进入地图时出现着色器报错。本版要求原版 Cuba Fastfile，避免继续使用该故障地图。只修复这 66 个字段的候选已通过离线检查，但未实机验证，未收入默认包。原本缺失的字幕可能仍不显示。
4. **视频、广播和其他常驻对白覆盖不完整。** 部分视频内嵌或外置对白仍是原声。789 个音频成员不是完整战役对白总数，不能据此推断全游戏已覆盖。
5. **翻译、响度、语气和接话仍需检查。** 角色样板的批准仅适用于当时试听的样板，不等于整批成品通过。当前包未取得完整战役实机与最终声音质量验收。
6. **安装版本有限制。** 只核对了 README 中说明的本地 PC 安装。其他游戏构建、语言包及 Mod 组合不在本次验证范围内。

本版尚未完成“原版 → 故障版 → 修复版”的游戏运行对照。不得把离线解码成功、文件摘要相同或安装测试通过写成实机修复通过。
