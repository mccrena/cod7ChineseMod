# 使命召唤7：黑色行动 中文配音 Mod

当前测试版本：**v1.0-beta**，发布日期：2026-11-06。

[下载 v1.0-beta 测试版](https://github.com/mccrena/cod7ChineseMod/releases/tag/v1.0-beta)

本版包含 789 个音频成员，合并了 19 条古巴语气修订，提供可回滚安装和卸载脚本。游戏程序、原版资源包、TTS 模型及重建地图不包含在下载包中。

本版尚未通过完整战役实机验收。开场梅森的 7 段常驻对白仍英文；部分试制语音存在急读或可能截尾的问题，视频等对白也未完整覆盖。默认包要求原版古巴地图，不安装未经实机验证的字幕地图修复。

## 安装与测试

下载 Release 中的 ZIP，完整解压，先阅读 README.zh-CN.md 和 KNOWN-ISSUES.zh-CN.md，再运行 INSTALL.cmd。卸载使用 UNINSTALL.cmd，保留安装器生成的备份。

适用范围仅为安装脚本校验通过的本项目 PC 游戏构建和 Japanese 语言槽中文汉化。其他构建未验证。

安装说明、已知问题及脚本源文件见 [release/v1.0-beta](release/v1.0-beta/)。反馈请附关卡、检查点、角色、台词和复现步骤。
